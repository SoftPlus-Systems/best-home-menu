Your menu is managed in Google Sheets

Edit the Google Sheet to change the live menu. Changes appear within about 5 minutes, and no publishing step is needed. Use this page to check a POS export for price changes and to make the table QR code.

Categories

Rename, re-order and pick an icon. The order here is the order on the menu.

Update prices from your POS export

Export the item list from the till (same format as menu.xlsx: Item Code, Description, Price, Family) and drop it here. Prices are matched by item code — your nicer menu names, categories and descriptions are kept. New till items are added as hidden so you can decide whether to show them.

Option 1 · Publish the file (recommended)

Your edits are saved in this browser. To put them live:

  1. Click Download menu.json.
  2. On GitHub, open the repository → folder data → Add file → Upload files, drop menu.json and click Commit changes.
  3. Netlify rebuilds automatically — the live menu updates in about 30 seconds.

Option 2 · Google Sheets (no publishing step)

Prefer editing a spreadsheet? Keep the menu in Google Sheets and the website reads it live.

  1. Download the CSV below and import it into a new Google Sheet (File → Import).
  2. File → Share → Publish to web, choose Comma-separated values (.csv), publish, copy the link.
  3. Paste the link into assets/config.js → sheetCsvUrl (one-time).

Columns: code, category, name, option, price, description, tags, visible. Rows with the same name in the same category become one dish with several sizes (e.g. Glass / Bottle). Set visible to “no” to hide an item.
